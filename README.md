# Quidquid: Factory Search

[![Downloads](https://img.shields.io/badge/dynamic/json.svg?label=Downloads&url=https%3A%2F%2Fmods.factorio.com%2Fapi%2Fmods%2Fquidquid-factory-search&query=%24.downloads_count)](https://mods.factorio.com/mod/quidquid-factory-search)

Adds an action to the [Quidquid](https://mods.factorio.com/mod/quidquid) palette:
`Shift` + `Alt` + left click on an item, fluid, recipe or resource in the
palette's results opens [Factory Search](https://mods.factorio.com/mod/FactorySearch)
with it selected.

A recipe is searched by its main product, or its only product, and a resource
by what mining it yields. The key can be rebound in Factorio's control
settings.

Requires Quidquid and Factory Search.

Resource patches appear in the palette with [Quidquid: Resources](https://mods.factorio.com/mod/quidquid-resources); since Quidquid 0.10.0 they are no longer built in.
